## [0.1.0] - 2026-08-05

### Added

- Signed Slack Events API webhook with replay protection.
- Slack member allowlist and DM-only defaults.
- GitHub pull request validation and user-token approval reviews.
- Optional randomized comments, dry-run mode, and GitHub Enterprise support.
- Container deployment, CI, dependency audit, and comprehensive mocked test suite.
